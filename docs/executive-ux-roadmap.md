## 3分後に言えること

> 「板金・整備工場のオーナーが、スマホ片手で今週の車検・オイル案内を見落とさず、確認してから LINE で送れる。」

## 代表3手（週次シナリオ A）

1. **ホーム** → 要対応（未紐付・送信失敗）と案内候補件数を確認
2. **リスト** → 顧客を選び送信シートで文面・金額を確認 → LINE 送信
3. **履歴** → 失敗があれば再送、未紐付があれば顧客に結びつける

## デフォルト画面から消すもの

- 技術用語（LINE User ID、Phase 番号、Cloudflare 表記）
- URL 全文の露出
- 開発者向けヒント

## 後半に残すもの

- 見積明細の手動編集（送信前調整）
- テンプレ文面の差し替え（将来・管理画面）
- Cron / AUTO_SEND（運用合意後）

## やらないこと

- 予約カレンダー・在庫・会計
- メール配信 UI
- AI 文面生成
- 多店舗 org 切替

## Phase UX-1 — シェル

**目的:** 全画面でフッターが画面最下部に固定され、iPhone の safe-area でも操作できる。

**対象:** `AppShell.tsx`, `index.css`

**受け入れ:**

- [x] コンテンツが短いページ（ホーム）でもフッターが画面最下部
- [x] フッター下にコンテンツが隠れない（main に padding-bottom）
- [x] ナビ各項目のタップ領域が 44px 以上

---

## Phase UX-3 — 顧客一覧・登録（一部）

**目的:** 店頭で「誰の車か」が一覧で分かり、新規登録が1画面で完結する。

**対象:** `CustomersPage`, `CustomerNewPage`, `customers.ts` API

**受け入れ:**

- [x] 一覧にナンバー・LINE 可否が表示される
- [x] ナンバーで検索できる
- [x] 新規登録でお客様＋お車（任意）を同じ流れで登録できる
- [x] LINE User ID はフォームに出さない（未紐付から来たときだけ案内文）

**やらないこと:** ウィザード分割、複数車両の一括登録

---

## Phase UX-5 — 共有リンク（一部）

**目的:** 見積発行後、スタッフが URL 全文を見ずにコピー・プレビューできる。

**対象:** `ShareLinkRow.tsx`, `QuoteEditPage.tsx`

**受け入れ:**

- [x] URL 全文が画面に表示されない
- [x] 各行に「開く」「コピー」がある
- [x] コピー成功のトースト

---

## Phase UX-2 — ホーム＋リスト

**目的:** 今週の案内候補が緊急度順で一目で分かり、リストで識別して送信できる。

**対象:** `HomePage`, `ListPage`, `ListTargetCard`, `listRules.ts`, `home.ts`, `auth.ts`, `AppShell`

**受け入れ:**

- [x] ホーム案内候補が緊急度順（満了後が最上段・色付き）
- [x] 0件のリストも表示されるが視覚的に控えめ
- [x] リスト行にナンバー・残日/LINE バッジ・電話が読める
- [x] ヘッダ subtitle が `ISSUER_JSON` の店舗名
- [x] 送信失敗リンクが履歴の「失敗のみ」フィルタへ

**やらないこと:** リストの一括送信、並び替え UI

---

## Phase UX-6 — 履歴（失敗優先・再送）

**目的:** 送信失敗がすぐ目に入り、理由を見て再送できる。

**対象:** `HistoryPage`, `HistoryJobCard`, `notifications.ts` logs API, `notificationLabels.ts`

**受け入れ:**

- [x] デフォルトタブ「要再送」（ホームから `?status=FAILED` でも同じ）
- [x] 「すべて」では失敗セクションが上、送信済みが下
- [x] 失敗行は赤枠・日本語ステータス・エラー理由表示
- [x] 「LINE で再送」が全幅・44px 以上
- [x] ナンバー・ルール名（日本語）が識別できる
- [x] 複数失敗時に「すべて再送」（要再送タブのみ）

**やらないこと:** メール再送、チャネル切替

---

## Phase UX-4 — 送信シート・見積導線

**目的:** リストから送信する前に金額・文面を確認し、必要なら見積を直して戻れる。

**対象:** `SendSheet`, `ListPage`, `QuoteEditPage`, `notifications` preview API, `Toast`

**受け入れ:**

- [x] 送信シートに合計・法定/最低の概要が表示される
- [x] 「見積を編集」「お客様画面」導線がある
- [x] 見積編集から「送信確認へ」戻るとシートが再開される
- [x] 保存して発行後、送信フローに自動復帰できる
- [x] LINE 送信ボタンがシート下部固定・44px 以上
- [x] 送信成功・コピー成功のフィードバック

**やらないこと:** シート内 iframe プレビュー、一括送信
